# Q3: which kind of error makes the difference?

Stage 1 point table (`docs/l3d/STAGE1_PLAN.md`, section 4.3). Values are means of squared camera-0 error (m², after the upstream median scale) per unit, on units where every model has an output.

- **Tier A** (any model): **gauge** = part removed by one Sim(3) per clip; then of the rest: **offset** = time mean of the GT motion group's error, **jitter** = the group's per-frame mean minus the offset, **residual** = per unit. Shares are of the mean squared error (MSE).
- **Tier B** (decoded-query models): **point** = target-camera point error moved into camera 0 by the GT pose (split into **depth** along the GT ray and **image-plane**), **pose** = the rest (camera error), **cross** = 2 point·pose. **2D px** = median error of the predicted pixel at the target frame (256-px units, `t > 0`).
- Squared errors are dominated by a few very large errors. **All units** shows the full MSE; **d ≤ 1** keeps units where every model's error is at most 1.0 (the largest APD threshold), so it describes errors that APD can still see.
