# B0 / B0-C: test-time ensembling (OpenD4RT 48CLIP, clip [0, 48))

`scripts/l3d/run_b0.py` (226 s; code `l3d/ensemble.py`). The ensembles average outputs already in the dump, so k <= 6 (design 1 has up to 6 source and 6 camera frames per point); k = 8 needs a new dump.

- **B0, model u2**: the query's output `P(u1, t1, t3, c)` averaged with `k - 1` outputs decoded from other source frames `t2` at the model's own `u2 = uv_hat(u1, t1, t2, t2)`, where the model calls the point visible (label-free). **GT u2** decodes the same `t2` from the GT pixel (perfect correspondences).
- **B0-C, T\***: the query's output in a reference camera averaged with `k - 1` outputs of the same query decoded in other camera frames, mapped to the reference by the SE(3) Umeyama fit `T*` per camera pair (label-free). **GT pose** maps them by the GT pose. Reference **t_t**: the self-frame output, which has no camera-frame error; **cam 0**: the clip's world frame (`t_t > 0`), a cross-frame output, where the camera checks apply.
- Every k averages over all size-`(k - 1)` subsets of a cell's other frames. **Gain** = 1 - mean relative error `|P - X| / |X|` of the ensemble / that of the single output, on the same cells (positive: ensembling helps); 95% CI from 1000 resamples of each subset's clips. **MSE gain** is the same on squared error, which ties to A3: with GT u2 and every source, what is left is T + C.
- Errors are in the reference camera (`c` for B0, `t_t` for B0-C) after the clip's global median scale.
